v0.2.0 UI redesign and release rule: 1) Portal Tooltip component summarizes option descriptions cleanly across TitleBar, VisorPanel, ClipQueuePanel, and modals; eliminated redundant resolution HUD, duplicate Ajustes/Motores pill, duplicate Prompt IA button in queue header, and duplicate timecodes inside clip cards. 2) ClipQueuePanel groups batch numbering/margins in a collapsible accordion, tucks clip -15s/-5s/+5s/+15s under a toggle, and renders completed/error/cancelled export alerts as a dismissible banner (onDismissJob) above Exportar Seleccionados so re-exporting is always possible. 3) User preference: every future change or fix must bump the semantic version across package.json, tauri.conf.json, Cargo.toml (and UI badges), push to origin main, and publish a matching tagged GitHub release.
