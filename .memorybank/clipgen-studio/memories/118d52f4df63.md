# Frontend Map (`src/`)

## Active Components & Files
- `src/index.css` & `src/assets/fonts/`: Global dark-studio styles and local Google Sans variable `.ttf` fonts (`GoogleSans-Variable.ttf` normal & `GoogleSans-Italic-Variable.ttf` italic) registered via `@font-face` and Tailwind v4 `@theme` (`--font-sans`, `--font-serif`, `--font-mono`).
- `src/App.tsx`: Root coordinator holding `url`, `metadata`, `activeStart`/`activeEnd`, `savedClips`, `selectedClipIds`, `clipStartIndex`, `options`, `jobs`, `AI_PROMPT_TEMPLATE`. Key helpers: `matchesMetadataVideo`, `isUrlMatchingMetadata`, `buildBatchRequests`, `handleAnalyze`, `handleAddClip(name, start, end, insertAtNumber?)`, `handleMoveClip`, `handleMoveClipToNumber`, `handleExportSelected`, `handleExportQualityPresetChange`, `handlePickFolder`, `handleImportJson`, `handleDirectPasteJson`.
- `src/components/TitleBar.tsx`: Custom window bar (`app_minimize`, `app_toggle_maximize`, `app_is_maximized`, `app_close`, `app_start_dragging`), URL input, **Pegar**, **Cargar**, **Extraer Transcripción** (`onOpenTranscription`), **Prompt IA**, **Ajustes**.
- `src/components/VisorPanel.tsx`: 70% left panel — HLS/MP4/WebM/YouTube embed player, resolution switcher (`selectedResolution`, `handleResolutionChange`), speed/audio sync, stall watchdog, zoomable minimap, and 3-zone NLE timeline.
- `src/components/ClipQueuePanel.tsx`: 30% right panel — global/current scope (`viewScope`: `"current" | "all"`, `hasLoadedVideo`), clickable `#displayNum` reorder badge (`onMoveClipToNumber`), `clipStartIndex`, global safety margins (`marginBefore`, `marginAfter`), per-clip time nudges, `qualityPreset`, `filenameFormat` (`"clean" | "full"`), folder picker/opener, JSON buttons, export CTA.
- `src/components/TranscriptionModal.tsx`: Editable `targetUrl` + **Pegar** + `Otra URL`, scope (`full` vs `range` when `targetMatchesLoaded`), language (`es`/`auto`/`en`), Whisper model (`small`/`medium`), emotion toggle, live progress + logs, **Cancelar**, `Título:`/`URL:` preview, **Guardar .txt**, **Copiar Texto**, **Copiar para IA** (`--clipgen`).
- `src/components/SettingsModal.tsx`: Engine binary updates & `ManualDownloadOptions` settings.
- `src/components/ImportJsonModal.tsx` & `src/components/PasteConfirmModal.tsx`: JSON clip importer UI.
- `src/types.ts`: TS DTOs matching Rust (`BinaryStatus`, `VideoMetadata`, `PreviewResolutionOption`, `AudioTrackOption`, `ClipSegment`, `SavedClipEntry`, `ManualDownloadOptions`, `ClipExportRequest`, `JobProgressEvent`, `JobState`).
- `src/utils/time.ts`: `formatTimecode`, `formatTimeShort`, `parseTimecode`, `parseFlexibleTimestamp`, `cleanClipTitle`.
- `src/utils/jsonParser.ts`: `parseClipGenJson` for importing AI-generated clip JSON blocks.
