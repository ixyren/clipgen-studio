# Rust Backend Map (`src-tauri/src/`)

## Modules & Commands (`lib.rs` -> `tauri::generate_handler![]`)
- `src-tauri/src/lib.rs`: Window commands `app_minimize`, `app_toggle_maximize`, `app_is_maximized`, `app_close`, `app_start_dragging`.
- `src-tauri/src/models.rs`: Shared DTOs (`ManualDownloadOptions`, `ClipExportRequest`, `SavedClipEntry`, `TranscriptionSegment`, `TranscriptionResult` with `video_title`, `TranscriptionProgressEvent`) + `format_timestamp`, `sanitize_filename`, `split_shell_args`.
- `src-tauri/src/binary_manager.rs`: Paths `get_binaries_dir`, `ytdlp_binary_path`, `ffmpeg_binary_path`; hidden console process builders `hidden_std_command` & `hidden_tokio_command`. Commands: `check_binaries_status`, `ensure_and_update_binaries`. Event: `binary-update-progress`.
- `src-tauri/src/ytdlp.rs`: Video metadata probing, local preview HTTP `/stream/` proxy, HLS playlist synthesis (`build_dash_hls_playlist`), raw JSON cache (`get_cached_raw_video_json`, `invalidate_cached_raw_video_json`), progress parsers. Commands: `fetch_video_info`, `start_full_download`, `cancel_job`. Event: `job-progress`.
- `src-tauri/src/clipper.rs`: Multi-clip download/cut/merge pipeline and queue persistence (`persistent_clips_path` -> `<binaries_parent>/saved_clips.json`). Commands: `export_clips`, `export_clips_batch`, `load_persistent_clips`, `save_persistent_clips`, `get_persistent_clips_file_path`, `get_default_download_dir`, `open_output_folder`, `pick_download_folder`.
- `src-tauri/src/transcription.rs`: Audio acquisition, Python transcription runner, and native `.txt` save dialog (`rfd::AsyncFileDialog`). Commands: `start_transcription`, `cancel_transcription`, `save_transcription_txt`. Event: `transcription-progress`.
