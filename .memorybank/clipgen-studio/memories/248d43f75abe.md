# Build, Test, Packaging & MemoryBank Commands

- Frontend typecheck + bundle: `npm.cmd run build` (`tsc && vite build` -> `dist/`)
- Offline Rust unit tests: `cargo test --manifest-path src-tauri/Cargo.toml --lib -- --skip e2e_verify` (30 lib unit tests)
- Full Tauri release build + installers: `npm.cmd run tauri build`
  - Executable: `src-tauri/target/release/clipgen-studio.exe`
  - NSIS installer: `src-tauri/target/release/bundle/nsis/ClipGen Studio_0.1.0_x64-setup.exe`
  - MSI installer: `src-tauri/target/release/bundle/msi/ClipGen Studio_0.1.0_x64_en-US.msi`
- MemoryBank CLI (uses `.memorybank/`, default namespace `clipgen-studio`):
  - `npm.cmd run memorybank -- stats`
  - `npm.cmd run memorybank -- list`
  - `npm.cmd run memorybank -- recall "<query>"`
  - `npm.cmd run memorybank -- search "<query>"`
  - `npm.cmd run memorybank -- store <type> "<name>" "<content>"`
- Workspace Antigravity plugin: `.agents/plugins/clipgen-memorybank/` (MCP server name `clipgen-memorybank`, storage `.memorybank/`).
