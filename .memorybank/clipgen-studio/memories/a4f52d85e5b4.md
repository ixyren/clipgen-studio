yt-dlp only enables deno by default; without a JS runtime it cannot solve YouTube n-challenge and downloads throttle to ~10KiB/s. binary_manager.rs js_runtime_args() detects deno/node/bun (PATH, Program Files nodejs, ~/.deno/bin) and returns --js-runtimes runtime:path; it is prepended in transcription.rs (audio download), clipper.rs (stream analysis), ytdlp.rs (fetch_video_info + download runner). Measured: 6 MiB/s default vs 18 MiB/s with node.
