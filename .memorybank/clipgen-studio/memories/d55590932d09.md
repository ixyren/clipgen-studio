Configured timeline mini-preview scrubber to use activeStreamUrl directly so it shares the viewport video's cached and buffered chunks, while remaining an independent media element. The main viewport video stays paused and never updates or reloads during drag; only the mini tooltip preview canvas renders frames in real-time. Upon releasing the playhead, the main viewport commits and seeks to the final dropped position. Also exposed the resolution selector directly in the transport marking bar next to playback speed and built all distinct available video heights in ytdlp.rs.
