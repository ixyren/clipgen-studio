# Transcription & Paralinguistic AI Pipeline (Transcripción)

## Frontend (`src/components/TranscriptionModal.tsx` & `src/App.tsx`)
- `App.tsx` computes `isUrlMatchingMetadata(url, metadata)` so changing top-bar URL without pressing Cargar transcribes the new URL instead of sticking to previous metadata.
- Modal has editable `targetUrl` input + **Pegar** + clear + **Otra URL** button in completed view; `hasRange` is only active when `targetMatchesLoaded`.
- Completed outputs: `buildTxtContent()` (`Título: ...
URL: ...

<formatted_text>`) used by **Guardar .txt** (`save_transcription_txt` native dialog) and **Copiar Texto**; `buildAiCopyContent()` prefixes `--clipgen` at line 1 for **Copiar para IA**.

## Rust Runner (`src-tauri/src/transcription.rs`)
- Resolves title via cached yt-dlp JSON or `--no-simulate --print before_dl:__CLIPGEN_TITLE__:%(title)s`.
- Range fast-path tries FFmpeg direct HTTP extraction (`try_fast_range_ffmpeg_audio`); falls back to `yt-dlp` light audio (`ba[protocol=https][abr<=96]/...` + `--concurrent-fragments 16`) with live `%`, speed, ETA, and cancellation (`cancel_transcription`).
- Spawns Python with `PYTHONIOENCODING=utf-8` & `PYTHONUTF8=1`.

## Python Engine (`src-tauri/scripts/transcribe_audio.py`)
- Embedded at compile time via `include_str!("../scripts/transcribe_audio.py")` (requires `cargo/tauri build` after edits).
- Pipeline: PCM extraction + O(1) RMS dBFS peak detection (`[PICO DE AUDIO]`) -> Faster-Whisper (`BatchedInferencePipeline`, `small`/`medium`) -> `sherpa-onnx` CED-Mini reactions (`[RISA]`, `[SUSPIRO]`, `[GRITO]`, etc.) -> `emotion2vec_plus_large.onnx` GPU SER (`[RABIA]`, `[ALEGRÍA]`, etc.).
